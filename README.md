# Telegram cashback bot
7th semester course work 
Данный бот структурирует информацию о ежемесячных условиях кэшбэка и умеет подсказывать оптимальную карту для покупки в определенной категории, а также для определенного MCC.

Список команд:  
/start - Начало работы  
/help - Помощь  
/add_card - Добавить карту  
/add_cashback - Добавить кэшбэк  
/edit_card - Редактировать карту  
/card_list - Список карт
